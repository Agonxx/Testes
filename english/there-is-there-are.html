There is / There are

Indicar a existência de coisas e pessoas

Quando usar?

  • Para dizer que algo existe ou está presente em algum lugar
  • There is (There's) → singular ou incontável
  • There are → plural

Estrutura

FormaSingularPlural
Afirmativa There is a cat. There are two cats.
Negativa There isn't a cat. There aren't any cats.
Interrogativa Is there a cat? Are there any cats?

Some vs Any

  • Use some em frases afirmativas: There are some books on the table.
  • Use any em negativas e perguntas: Are there any seats available?

Exemplos com tradução

There is a supermarket near here.

Tem / Há um supermercado perto daqui.

There are three messages for you.

Tem três mensagens para você.

There isn't any milk in the fridge.

Não tem leite na geladeira.

Is there a bathroom on this floor?

Tem banheiro neste andar?

Are there any questions?

Tem alguma pergunta?
