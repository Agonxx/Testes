2nd & 3rd Conditional

Situações hipotéticas, imaginárias e impossíveis no passado

2nd Conditional — Hipotético (presente/futuro)

  • Para situações imaginárias ou improváveis no presente ou futuro
  • A condição é contrária à realidade atual
ParteTempo verbalExemplo
If (condição)Past SimpleIf I had more time...
Resultadowould + verbo base...I would travel more.

If I were you, I would apologize.

Se eu fosse você, eu pediria desculpas.

She would buy that car if she had the money.

Ela compraria aquele carro se tivesse o dinheiro.

Nota: com "If I were you" usa-se were para todos os pronomes (mais formal/correto), mas "was" também é comum na fala.

3rd Conditional — Impossível (passado)

  • Para situações que não aconteceram no passado
  • Imaginar um resultado diferente para algo que já passou
ParteTempo verbalExemplo
If (condição)Past PerfectIf I had studied...
Resultadowould have + past participle...I would have passed.

If he had left earlier, he wouldn't have missed the flight.

Se ele tivesse saído mais cedo, ele não teria perdido o voo.

I would have called you if I had known you were there.

Eu teria te ligado se eu soubesse que você estava lá.

Mixed Conditional — Mistura dos dois

  • Condição no passado, resultado no presente (ou vice-versa)

If I had studied medicine (3rd), I would be a doctor now (2nd).

Se eu tivesse estudado medicina, eu seria médico agora.

Comparativo completo dos Conditionals

TipoRealidadeEstruturaExemplo
0 Sempre verdade If + present, present If you heat ice, it melts.
1st Possível If + present, will If it rains, I'll stay home.
2nd Hipotético If + past, would If I had money, I would travel.
3rd Impossível (passado) If + past perfect, would have If I had studied, I would have passed.
